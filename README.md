# reratos

`reratos` is an R package providing a comprehensive interface to the [Eratos data management platform](https://www.eratos.com). The package enables researchers and data scientists to programmatically access, retrieve, and manage sensor data, workflows, observations, and other research data through the Eratos API.


## Getting started

### Installation

Currently available on [GitHub](https://github.com/byzheng/reratos) only. Install with:

```r
# Install from GitHub
remotes::install_github('byzheng/reratos')
```
